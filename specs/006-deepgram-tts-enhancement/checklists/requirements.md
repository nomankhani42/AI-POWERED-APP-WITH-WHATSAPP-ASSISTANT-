# Requirements Checklist: Deepgram Aura TTS Enhancement

- [x] Active and rollback providers are unambiguous.
- [x] Public TTS and `SpeechChunk` contracts remain stable.
- [x] Empty, incremental, oversized, failed, timed-out, and cancelled inputs are specified.
- [x] Model, speed, sample rate, and deadline configuration is defined and validated.
- [x] Provider payload and Flush limits are addressed.
- [x] Observability excludes text, audio, and secrets.
- [x] Automated and manual validation steps are documented.
- [x] Cartesia removal is explicitly out of scope.
- [x] Constitution and older provider-specific specifications carry the current-state amendment.
